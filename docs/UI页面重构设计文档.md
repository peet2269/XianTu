# 仙途 · UI 页面重构设计文档

> 用途：给接手 UI 重构的人 / AI 当作设计稿和提示词。**动任何页面前先读完第 0～3 章，再看对应页面的章节。**
> 范围：局内（/game）所有页面、局内弹窗；局外页面复查放在第 7 章。
> 配套：配色令牌与通用类见 `docs/UI仙侠风格重构指南.md`；逻辑改动背景见 `重构协作计划.md`、`多AI并行任务提示词.md`。
> 状态：**设计稿**。D1–D3 已定（最外层三栏布局不变，只美化）；D4、D5 未确认前按默认方案。

## 0. 为什么要重写这份文档

### 0.1 上一轮失败在哪

2026-09-27 第一轮局内改造只做了"换皮"：配色、按钮、图标换了，**页面骨架、栏位、信息排布全部沿用旧版**。用户看到的效果是"每个页面都没变"。截图暴露的具体问题：

| 问题 | 表现 |
| --- | --- |
| 功能页骨架没变 | 各功能页内部仍是旧版排布，只换了颜色（最外层三栏按用户要求保持不变） |
| 半屏空白 | 人物详情只占上 60% 高度，下方一片空；宽屏下卡片被拉到 800px，数值条横穿整张卡 |
| 框套框 | 外壳框 → 名牒框 + 内细框 → 小节卡框 → 六司格子框，四层边框，像后台管理系统 |
| 没有视觉重心 | 名牒的境界 / 灵根 / 所在 / 修为提示散在 2000px 宽度上，各自漂着 |
| 重复信息 | 面板标题条"人物详情"独占一行，名牒里又写一遍名字 |
| 左栏放不下 | 每项两行字，1080 高屏幕都装不下，"系统设置""返回道途"被截断 |
| 字小、对比低 | 12px 灰字标签在深底上看不清 |
| 数据不可读 | "先天 10 0"——没人知道 0 是后天加成 |
| 空数据硬画 | 灵气 0/1 画一根空条；凡人没有修为进度就剩一句贴边的话 |

### 0.2 这次的硬性原则（违反任何一条都算没做完）

1. **最外层三栏不动，功能页内部要重排**。外壳只做美化（第 2 章）；每个功能页必须按第 5 章的新线框重排，验收时对比新旧截图，页面内部布局差异要一眼可见。
2. **一屏装满、不留大片空白**：1920×1080 下内容区高度利用率 ≥ 85%；内容少时改用更紧凑的版式，而不是把卡片拉宽。
3. **边框最多两层**：页面容器 1 层 + 内容块 1 层。块内分组用留白、分隔线、底色深浅区分，不再加框。
4. **限制行宽**：正文 ≤ 46em；数值条 ≤ 360px；卡片宽度用 `minmax()` 限制上下限，不允许随屏幕无限拉长。
5. **字号底线**：正文 ≥ 15px；标签 / 说明 ≥ 13px；只有角标、计数可以用 12px。弱文字（`--cc-text-3`）不能用在需要阅读的内容上。
6. **不写没人懂的数字**：所有数值都要带名称或单位；加成写成 `先天 10 · 后天 +0`。
7. **空数据有专门状态**：没有进度就不画进度条；列表为空给一句说明 + 可执行的下一步按钮。
8. **每个页面有自己的版式**：不许所有面板都套同一个"卡片网格"。第 3 章给出 6 种版式，按页面挑。
9. **标题不重复**：功能页头部 = 返回 + 页面名 + 页面级操作，合并在同一行，不再单独占一整行再套框。
10. **每改一页交一次截图**：1920×1080、1440×900、390×844（手机）三张，暗 / 亮各一套，用户确认后再改下一页。

### 0.3 决策

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| D1 | 主界面骨架 | **已定：最外层布局不变**（顶栏 + 左功能栏 + 中正文 + 右状态栏），只做美化 |
| D2 | 功能页打开方式 | **已定：保持现状**，盖住中栏，右栏隐藏 |
| D3 | 角色状态放哪 | **已定：保持右状态栏**，按 2.4 美化 |
| D4 | 宗门路由 | 默认：UI 改单页标签，旧子路由保留兼容（访问子路由时自动切到对应标签）；备选：删除子路由 |
| D5 | 局外页面是否也重做 | 默认：本轮只做局内，局外按第 7 章列出问题，二期处理 |

## 1. 设计语言

### 1.1 意象对照

| 界面元素 | 意象 | 视觉做法 |
| --- | --- | --- |
| 主界面 | 书案 | 深色案面（`--gm-page-bg`）+ 淡水墨纹，正文是一卷摊开的书 |
| 左功能栏 | 法器架 | 玉璧图标 + 名称单行，分组用金色短线 / 朱印小签 |
| 顶栏 | 天幕 | 地点、灵气玉珠、时辰做成一条卷轴签 |
| 右状态栏 | 名牒 | 顶部书法大名 + 玉璧头像，下方数值、境界、天赋、状态 |
| 功能页 | 展开的卷轴 | 页头有卷轴轴头（左右两端深色短条），页面内容在卷面上 |
| 选中 | 金线 + 朱印 | 金色左竖条、朱印小方章；不用大面积色块 |
| 空态 | 水墨留白 | 大号书法单字水印 + 一句话 + 一个动作按钮 |

### 1.2 版面网格

- 基准间距：4px 的倍数，常用 8 / 12 / 16 / 24 / 32。
- 页面内边距：桌面 24px，平板 16px，手机 12px。
- 圆角：容器 8px，块 6px，签条 4px。不再出现 14px 大圆角。
- 阴影：只给浮层（抽屉、弹窗、下拉）用，常驻块不加阴影。

### 1.3 字号阶梯

| 用途 | 字号 | 字体 |
| --- | --- | --- |
| 页面名 / 角色名 | 28–36px | 书法（`--cc-calligraphy`） |
| 块标题 | 17px，字距 0.15em | 宋体加粗 |
| 正文 / 叙事 | 16–17px，行高 1.9–2 | 宋体 |
| 列表主文字 | 15px | 宋体 |
| 标签 / 说明 | 13px | 宋体 |
| 角标 / 计数 | 12px | 宋体，等宽数字 |

### 1.4 沿用与作废

- **沿用**：`src/styles/xian-tokens.css` 的 `--cc-*`、`src/styles/game-theme.css` 的 `--gm-*` 令牌和品阶色 `--q-*`、`src/utils/qualityTone.ts`、`cc-btn` / `cc-input` / `cc-segmented` / `cc-modal*`。
- **作废重做**：第一轮改过的 `GameView`、`TopBar`、`LeftSidebar`、`RightSidebar`、`MainGamePanel`、`CharacterDetailsPanel`、`InventoryPanel`、`SkillsPanel` 的**布局部分**全部按本文重写；脚本逻辑保留。
- `gm-sec`（小节卡）只在确需分块时使用，**禁止嵌套**。

## 2. 主界面外壳（保持三栏，只做美化）

> 决策 D1：**最外层布局不变**——顶栏 + 左功能栏 + 中间正文 + 右状态栏，功能页打开时盖住中栏、右栏隐藏，这些行为全部保留。本章只解决"丑"的问题：比例、字号、间距、边框、空数据、放不下。

### 2.1 保持不变的部分

| 项 | 保持 |
| --- | --- |
| 栏位 | 顶栏 + 左功能栏 + 中正文 + 右状态栏 |
| 功能页 | 盖住中栏，左栏保留，右栏隐藏（`panel-mode`） |
| 收起按钮 | 左右栏都能收起，按钮贴在栏边 |
| 移动端 | ≤768px 左右栏变抽屉，功能页全屏 |
| 入口与顺序 | 角色信息 / 修炼系统 / 事件探索 / 社交势力 / 系统功能 五组，入口不增不减 |

### 2.2 顶栏（TopBar）

现状问题：左中右三块各自漂着，灵气细条看不出数值含义，整体偏暗、字小。

- 高 56px。左：书法"仙途" + 名字牌（朱印单字 + 名字 + 境界）；中：地点 · 灵气 · 时辰；右：主题切换、全屏。
- 中间信息条改成**一条完整的卷轴签**：两端有轴头装饰，内部三段用菱形点分隔，字号 14px，不再是一条淡线框。
- 灵气浓度：细条换成**5 颗玉珠**（按 20 一档点亮）+ 数值 + 档位字（稀薄 / 适中 / 浓郁 / 充沛），悬停说明修炼影响。
- 名字牌点击 = 打开/收起右状态栏（方便收起后找回）。
- 窄屏按优先级隐藏：先藏境界，再藏灵气档位字，最后地点只留末级。

### 2.3 左功能栏（LeftSidebar）

现状问题：每项"图标 + 名称 + 描述"两行，项高约 56px，1080 高屏幕都放不下，"系统设置""返回道途"被截；分组名是一行小灰字，很散。

- 宽度保持 228px；**每项改为单行**：玉璧图标（28px）+ 名称（15px），项高 40px；原来的描述文字（"修为境界状态"等）移到悬停提示。
- 分组名改成**竖排朱印小签**或左侧金色短线 + 13px 金色字，组间距 12px，组内间距 2px。
- **900px 高度内必须放下全部入口 + 底栏**，放不下时只有"系统功能"组内部滚动，其他组不动。
- 当前页：整行淡金底 + 左侧 3px 金竖条 + 图标玉璧点亮。悬停：名称变亮、图标外圈转动。
- "返回道途"固定在栏底，与底栏合并成一行：`[归] 返回道途 · V1.x · GitHub · 赞助`；现实时间移到悬停提示，不再单独占一行。

### 2.4 右状态栏（RightSidebar）

现状问题：卡片套卡片，四个数值各占一张卡；灵气 0/1 这种数据也画空条；"角色状态"标题占一整行。

- 宽度保持 276px；去掉"角色状态"标题行，改为顶部**名牒头**：玉璧头像（书法单字）+ 书法名字 + 灵根 · 天资。
- 四维数值：一个块内四行，每行 `图标 名称 …… 当前/上限` + 细条；上限 ≤ 1 或缺失时**只显示数值不画条**；低于 30% 数值变红。
- 境界：书法境界名 + 进度环（替代横条）+ 百分比；无进度数据时显示"等待仙缘"一行说明，不画空环。可突破 / 可冲刺用朱印小签提示。
- 声望：称号 + 数值一行。
- 天赋神通、状态效果：签条（chip），可折叠；状态效果的"增 / 减"用小方印区分颜色，剩余时间放签条右侧。
- 全栏只有一层分隔（块之间用分隔线），**不再每项一张卡**。

### 2.5 中栏正文区

见第 4 章。要点：正文限制行宽居中、字号 17px、叙事色调低饱和、行动选项做成"签"。

### 2.6 功能页容器（GameView 的 panel-overlay）

现状问题：标题行"← 返回 + 圆盘 + 人物详情"独占一行，下面 `panel-shell` 再套一层大圆角框，框里各页面又自带框，层层嵌套。

- 头部一行 56px：`← 返回` ｜ 书法页面名（22px）｜ 页面级操作按钮（来自 `panelBus`，**带文字**）。
- **去掉 `panel-shell` 外框**，页面内容直接铺在案面底色上；由页面自己决定是否需要块。
- 页面内容最大宽度 1440px 居中，超宽屏两侧留白，不拉伸。
- 页面自己负责滚动；头部吸顶。

### 2.7 全局观感修正（外壳与所有页面通用）

- 字号：正文 15–17px，标签 13px，角标 12px；`--cc-text-3` 只用于次要说明，不用于需要阅读的内容。
- 暗色底加一层极淡的水墨纹理（CSS 径向渐变叠加，不用图片），避免大面积死黑。
- 金色只用于：分组线、当前项、数值、标题装饰。正文、按钮文字不用金色。
- 圆角统一：容器 8px、块 6px、签条 4px。
- 所有 emoji 换 lucide 图标或书法单字。

## 4. 叙事主界面（MainGamePanel + FormattedText）

版式：**叙事卷**（外壳中栏，见 2.5）。

### 4.1 结构

```text
┌ 叙事卷 ────────────────────────────────────────┐
│ ─── 仙道1000年3月12日 08:00 ───  [回退3][事件][变更2] │ ← 回合印记行，按钮带文字
│                                                 │
│   正文（首行缩进 2 字，行宽 ≤ 46em）                │
│   〔判签〕内嵌在正文里                               │
│                                                 │
│ ───────────── 何 去 何 从 ─────────────           │
│ [壹 收拾财物随秦岚撤往流火坊市] [贰 询问暗哨人数……]   │
│ [叁 ……]                        [肆 ……]            │
│ [伍 ……（奇数项独占一行）]                          │
└─────────────────────────────────────────────────┘
┌ 输入栏 ─────────────────────────────────────────┐
│ [短期记忆 2]  请输入您的选择或行动……            [落笔] │
└─────────────────────────────────────────────────┘
```

### 4.2 要点

- **短期记忆**从顶部移到输入栏左侧的小按钮，点开是向上展开的抽屉（最多 60vh）。
- 回合印记行：时间用**游戏内时间**（`gameStateStore.gameTime`），不再用现实时间。
- 生成中：印记行变成"天道感应中 · 已写 N 字"+ 重置按钮；正文区显示流式文字；行动签整体置灰不可点。
- 玩家上一句输入：放在正文上方，左侧朱印"我"，一行截断，可展开。
- 思维链：折叠条，默认收起，展开后最高 320px 内部滚动。
- 判签（FormattedText 的判定卡）：横向一条，左侧结果印章（成 / 败 / 大成 / 完美，书法单字），右侧"幸运 +4 · 判定值 42 · 难度 30"一行，细节折叠。
- 叙事文字色：环境【】青、对话赭金、心理紫灰斜体——沿用 `--gm-text-*`，**不得回到高饱和蓝 / 橙 / 紫**。
- 行动签 5 个以内两列；超过 6 个改为单列。
- 空态（开局生成失败）：显示书法"缘"字水印 + 原提示 + "返回道途"按钮。

## 5. 各功能页设计

> 每页格式：**版式 / 线框 / 信息分区 / 逻辑联动（之前改过的逻辑要在页面体现的地方）/ 空态 / 验收**。

### 5.1 人物（CharacterDetailsPanel）— L1 名牒 + 正文

```text
┌ 名牒竖卷 320px ─┐ ┌ 正文 ─────────────────────────────────────┐
│ [玉璧 修]        │ │ [根基] [修行] [人缘] [行囊]   ← 书签式竖/横标签 │
│ 修 士（书法 36） │ │                                          │
│ 男 · 人族 · 16岁 │ │ 根基页：                                   │
│ 出身：遗弃荒原之孤▸│ │  六司 —— 六边形图（左）+ 六行明细（右）        │
│ ──────────       │ │     根骨 10 = 先天 10 · 后天 +0             │
│ 境界  凡人        │ │  天资 / 灵根 —— 一条横幅，点开详情            │
│ 灵根  双生灵根·极品▸│ │  天赋 —— 签条                              │
│ 所在  焚鼎洲·…    │ │                                          │
│ ──────────       │ │ 修行页：主修功法 / 神通技能 / 三千大道摘要      │
│ 修为：等待仙缘      │ │ 人缘页：结识人数 · 人心所向 · 结缘录 · 宗门身份 │
│ （无进度不画条）    │ │ 行囊页：灵石折算 · 物品摘要 → 跳转行囊页        │
└─────────────────┘ └──────────────────────────────────────────┘
```

- 打开功能页时右状态栏隐藏，所以名牒竖卷里要放四维（气血 / 灵气 / 神识 / 寿元，紧凑四行）+ 境界、灵根、所在、修为。
- 六司必须用图形（六边形雷达或六枚玉印）+ 明细表，明细写清"先天 / 后天"。
- 声望用称号（籍籍无名 / 小有名气……）+ 数值。
- 法身页（酒馆环境）：`BodyStatsPanel` 放到正文区，单独一个标签。
- 空态：无角色数据 → 水印"缘" + "重新探查"。
- 验收：1920×1080 下正文区无大片空白；名牒信息集中在左栏，不漂散。

### 5.2 行囊（InventoryPanel）— L2 格架 + 详情

```text
┌ 页头：← 返回  行 囊            [整理] ──────────────────────────────┐
│ 分段：[物品 12] [法宝 1/6] [财产]    搜索…   分类▾   排序▾           │
├───────────────────────────────────────────────┬────────────────────┤
│ 格架：72×72 方格，图标 + 品阶色描边 + 右下数量   │ 详情栏 360px        │
│ ▢▢▢▢▢▢▢▢▢▢                                   │ 玉璧大图标          │
│ ▢▢▢▢▢▢▢                                      │ 书法名（品阶色）     │
│ 名称悬停显示；选中格金框                        │ 类型 · 品阶 · 品级   │
│                                               │ 描述 / 增幅 / 特效  │
│                                               │ [装备] [使用] [丢弃]│
└───────────────────────────────────────────────┴────────────────────┘
```
